前言

Markdown大法吼

接触Markdown差不多有大半年了，真是越来越爱~

因为蛋疼的WordPress不支持Markdown换了各种博客系统：Typecho，Hexo，Ghost，PageKit等等...包括自己开发的一套博客系统。

 

然后溜达一圈又回来了，无他，目前就觉得WordPress相对而言比较完美的。所以现在博客用那个markdown.js库编辑器。好是好，但是丑啊...

一直使用Editor.md编辑器，真心好使。连我的为知笔记都是用它：

本来16年中旬就想弄的，一直就拖到现在...主要之前找不到前台渲染的方案。不过前段时间灵感一闪，有了办法，没想到成功了。

说明

WP Editor.MD是一个漂亮又实用的在线Markdown文档编辑器。

基于Editor.md构建对WordPress平台的支持。

使用WordPress Jetpack的Markdown模块来解析和保存内容。

特征

  • 支持实时预览、代码插入、代码折叠等功能；
  • 支持 Emoji 表情
  • 支持 ToC（Table of Contents）、Github Task lists 等 Markdown 扩展语法
  • 支持 TeX 科学公式（基于 KaTeX）、流程图 Flowchart 和 时序图 Sequence Diagram

以上划线的目前不支持，未来版本支持

安装

怎么安装你真的真的不会吗？

不过，请把文件夹重命名为：WP-Editor.MD，否则会出现不正常的现象！

可能会有提交WordPress官方的计划。
